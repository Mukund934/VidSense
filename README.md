# VidSense AI

**Understand every video.**

VidSense AI transforms YouTube videos into interactive, searchable knowledge — letting you ask questions,
find exact moments, explore transcripts and comments, and get evidence-grounded answers.

> Ask. Explore. Understand.

---

## What makes it different

Most tools turn a video into an answer. VidSense turns it into a **record**.

Every claim in an answer carries a receipt: a verbatim transcript span, the exact timestamp it came from, a
confidence band, and a jump-to-moment link. Answers separate what the **video says** from what **viewers
say** in the comments from **external sources** from **AI inference** — and say plainly when the video does
not address your question at all.

The timestamp is not generated by the model. The model emits a cue index; the timestamp is a lookup in our own
array. A wrong timestamp is structurally impossible to produce.

## Status

Early development. Architecture is settled; implementation is in progress.

## Stack

- **Next.js** (App Router) · TypeScript · Tailwind
- **Firebase** — Authentication (Google Sign-In) and Cloud Firestore
- **Gemini** — video understanding and grounded answering
- **YouTube Data API v3** — public metadata and comments

## Development

```bash
npm install
cp .env.example .env.local   # fill in your own keys
npm run dev
```

The test suite runs fully offline against recorded fixtures — no API keys required:

```bash
npm test
```

## Principles

- **Never possess audiovisual content.** VidSense reads and reasons; it does not download, store or serve
  video or audio bytes.
- **Untrusted by default.** Transcripts, descriptions and comments are third-party data. They are never
  treated as instructions to the system.
- **Free-first.** The application is designed to run on free tiers during development and early use, with
  every paid dependency identified before it is incurred.
